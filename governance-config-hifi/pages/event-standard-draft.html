事件等级候选口径

等级由 Agent 给候选，由人确认
等级 判定条件摘录 来源标记 对时限的影响 状态
紧急 影响通行安全、存在人身风险或舆情风险 Agent建议 取该细类等级为「紧急」的时限行 启用
一般 不影响通行安全、无即时风险 Agent建议 取该细类等级为「一般」的时限行 启用

等级只决定候选口径，不代替立案人判定；发布后只作用于新事件。

该细类尚无等级候选 → 事件仍可立案，等级由人在待立案页手动指定。

未配置等级不影响立案，但该事件不会命中自动结案规则。

人工必确认字段（受控清单 · 只能勾选）

不可新增自定义字段

受控清单只能勾选，不能新增自定义字段。清单内未确认项不得提交立案派发。

Agent 不能自动立案、确认责任、派发、结案或触发外场核查。

本网格尚无唯一主责任人。事件可以匹配到此网格，但立案时不能派发。

需要先在「空间与责任」补齐唯一主责人；补齐前该网格的派发按钮保持禁用。
